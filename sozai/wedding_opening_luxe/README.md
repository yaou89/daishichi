## ナチュラル版から上げたところ

- **金箔の文字**：グラデーションと細かいラメの入った金箔に、立体感（エンボス）とやわらかな光をつけ、文字の上を光が流れます
- **紋章のアニメーション**：月桂樹のリースが下から伸びて、イニシャル「K & M」が浮かび上がるオープニング
- **空気感**：ベルベット調のネイビー、斜めに差す光、奥行きのある光のボケ（手前と奥で動く速さが違う）、十字に光る粒、フィルムの粒子、周辺減光
- **映画のようなストーリー**：上下に黒帯（シネマスコープ）が入り、写真が全画面でゆっくり動き、切り替わりの瞬間にレンズフレアが走ります
- **時計の文字盤のようなカウントダウン**：目盛り付きの二重リング、金の弧が一周し、先端が光ります
- **クライマックス**：BGMの全楽器の和音に合わせて光がはじけ、名前が金箔で描かれます
- **書体**：本文は細い明朝（Noto Serif CJK Light）、英字はローマ碑文調の Cinzel と、正統派の筆記体 Pinyon Script
- **BGM**：本物の楽器のサンプル音源（FluidR3_GM、MITライセンス）で鳴らしたオリジナル曲。シーンの切り替えは小節の頭に合わせています

## お客様用に作るときの手順

1. `config.json` をコピーして、名前・日付・プロフィール・メッセージを書き換える（`initials` は紋章の文字）
2. 写真を置いて `photo` 欄にファイル名を書く
   - プロフィール写真：縦長（3:4）
   - ストーリー写真：横長。シネマスコープで上下が少し切れるので、顔が真ん中寄りの写真がおすすめ
3. 納品版は `"watermark": ""` にする
4. 書き出す

```bash
python3 make_movie_luxe.py --config 田中様.json --out 納品_田中様.mp4
python3 make_movie_luxe.py --config 田中様.json --preview 8 30 47    # 静止画だけで確認
```

4コアのPCで書き出しは10分前後かかります（高画質設定のため）。完成ファイルは約70MBです。

### 必要なもの

- Python 3.9 以上、`pip install numpy pillow mido`
- ffmpeg
- 明朝体：Noto Serif CJK JP Light を推奨（Linux なら `apt install fonts-noto-cjk-extra`）。無い場合は通常の明朝体を使います
- BGMを作り直す場合：`fluidsynth` と `FluidR3_GM.sf2`（`apt install fluidsynth fluid-soundfont-gm`）

### 曲の差し替え

`"bgm": "song.mp3"` を指定すると、その曲を使います。市販の曲を使う場合は、ISUM（音楽著作権の申請）が必要になることが多いので、お客様と式場に確認してもらってください。
