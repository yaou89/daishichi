# ココナラ出品プラン：結婚式オープニングムービー

## なぜこれを選んだか（売れやすいと考えた理由）

1. **オープニングムービーは最初の1本に選ばれやすい**
   プロフィールムービー（5〜8分）やエンドロールは、写真集めもやり取りも大変です。オープニングは1〜2分と短いので、お客様は頼みやすく、出品者も早く納品できます。実績とレビューを早く貯められます。
2. **「くすみカラー × ナチュラル × アーチフレーム」はウェディングの定番トレンド**
   ボタニカル（ユーカリ）、アイボリー、ゴールドの細い線、英字の筆記体、縦書きの明朝体。前撮りや招待状と雰囲気を合わせやすく、会場を選ばないデザインにしています。
3. **BGMの著作権トラブルを避けられる**
   式場で市販曲を使うと、ISUMの申請や費用が必要になることが多く、お客様の悩みどころです。このムービーは**オリジナルBGM付き**なので「曲の手続き不要」を売りにできます。
4. **カウントダウン → 入場の流れが入っている**
   「5、4、3、2、1」から2人の名前が出て入場、という流れは会場が盛り上がるので人気の演出です。
5. **作り直しが速い**
   `config.json` を書き換えて実行するだけなので、1件あたりの作業時間はヒアリングと写真の調整が中心になります。低めの価格でも時給が保てます。

## 価格設定（案）

| プラン | 価格 | 内容 |
|---|---|---|
| ベーシック | **5,000円** | サンプルと同じ構成（約80秒）、写真6枚、文章の変更OK、修正2回、オリジナルBGM |
| スタンダード | 8,000円 | ベーシック＋写真10枚まで、メッセージ画面の追加、配色の変更（ブルー系／ピンク系など） |
| オプション | ＋1,000円 | 特急納品（3日以内） |
| オプション | ＋500円 | 写真1枚追加 |
| オプション | ＋1,500円 | 持ち込み曲に合わせた尺の調整（ISUMの手続きはお客様側） |

- 最初の3〜5件は **「モニター価格 3,980円（レビュー投稿にご協力ください）」** にしてレビューを先に集めるのがおすすめです。
- 相場は数千円〜1万円台が多いので、実績が5件ほど貯まったらベーシックを6,000〜7,000円に上げる目安です。

## よくある質問（案）

- **Q. 写真の枚数を増やせますか？** → オプションで追加できます（1枚500円）。
- **Q. 色を変えられますか？** → スタンダードプランでブルー系・ピンク系などに変えられます。
- **Q. DVDにできますか？** → MP4での納品です。DVDが必要な場合は、式場やDVD作成サービスにご相談ください。
- **Q. 好きな曲に変えられますか？** → 曲の長さに合わせて調整できます（ISUMの手続きはお客様側でお願いします）。
