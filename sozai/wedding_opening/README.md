# 結婚式オープニングムービー（くすみカラー × ナチュラル）

ココナラ出品用のサンプルムービーと、お客様ごとに作り直すための生成ツール一式です。

| ファイル | 内容 |
|---|---|
| `wedding_opening_sample.mp4` | サンプルムービー本編（80秒 / 1920×1080 / 30fps / BGM付き / 右上に「SAMPLE」の透かし入り） |
| `coconala_thumbnail.jpg` | ココナラのサービス画像（1220×1240） |
| `stills/` | 各シーンの静止画（出品ページの2枚目以降の画像に使えます） |
| `coconala_listing.md` | 売れやすくする工夫・価格設定・出品文のたたき台 |
| `config.json` | 名前・日付・プロフィール・写真・文章の設定ファイル |
| `make_movie.py` | ムービー生成スクリプト |
| `music.py` | オリジナルBGM生成（自作曲なので著作権の心配なし） |
| `make_thumbnail.py` | サムネイル生成 |
| `fonts/` | 英字フォント（Great Vibes / Cormorant Garamond・SIL OFLライセンス） |

## 構成（BGMの小節に合わせてシーンが切り替わります）

| 時間 | シーン |
|---|---|
| 0:00〜0:06 | Welcome to our wedding（ボタニカルが咲き広がる） |
| 0:06〜0:19 | ゲストへのメッセージ（縦書き・2画面） |
| 0:19〜0:29 | 新郎プロフィール（アーチフレーム写真） |
| 0:29〜0:38 | 新婦プロフィール |
| 0:38〜0:51 | Our Story（思い出の写真4枚） |
| 0:51〜0:58 | Thank you メッセージ |
| 0:58〜1:04 | Coming soon「まもなく新郎新婦の入場です」 |
| 1:04〜1:12 | カウントダウン 5→1 |
| 1:12〜1:20 | 2人の名前＋日付 → 白にフェードアウト（ここで入場） |

## お客様用に作るときの手順

1. `config.json` をコピーして、名前・日付・プロフィール・メッセージを書き換える
2. 届いた写真をこのフォルダに置き、`photo` 欄にファイル名を書く（例 `"photo": "photos/groom.jpg"`）
   - プロフィール写真は縦長、Our Story の写真は横長（3:2）がきれいに収まります（自動で中央を切り抜きます）
3. 納品版では `"watermark": ""` にして透かしを消す
4. 書き出す

```bash
python3 make_movie.py --config customer.json --out 納品_田中様.mp4
python3 make_movie.py --config customer.json --preview 25 45   # 気になる場面だけ静止画で確認
```

4コアのPCで書き出しは約2〜3分です。

### 必要なもの

- Python 3.9 以上、`pip install numpy pillow`
- ffmpeg
- 明朝体フォント：Noto Serif CJK JP（Linux）、ヒラギノ明朝（Mac）、游明朝（Windows）のどれかがあれば自動で使います。無い場合は `make_movie.py` の `MINCHO_CANDIDATES` にパスを追加してください。

### 曲を差し替えたいとき

`"bgm": "song.mp3"` のように指定すると、そちらを使います（80秒より長い曲は自動でフェードアウト）。
市販の曲を式場で流す場合は、ISUM（音楽著作権の申請）が必要になることが多いので、お客様と式場に確認してもらってください。
空欄のままなら、自作のオリジナルBGM（カノン進行のピアノ曲）が自動で入ります。

### 色を変えたいとき（スタンダードプラン用）

`make_movie.py` の先頭にある `TEXT / GOLD / BLUE / PINK / SAGE` の色コードを書き換えると、全体の配色が変わります。
